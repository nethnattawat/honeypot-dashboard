สิ่งที่ควรทำกับ ONU ที่เราดูแลWhat to do on the ONUs we manage

  • ปิด Telnet, SSH, HTTP 80/8080 ฝั่ง WAN เป็นค่าเริ่มต้นClose Telnet, SSH and HTTP 80/8080 on the WAN side by defaultทุกพอร์ตที่เปิดออก internet ถูกสแกนเจอภายในไม่กี่นาที ไม่ใช่หลายวันEvery port open to the internet is found within minutes, not days
  • ถ้าจำเป็นต้องเปิด ให้จำกัดต้นทางด้วย ACLIf it must be open, restrict the source with an ACLรับเฉพาะ IP ของระบบที่ต้องใช้จริง และปิด Telnet ทิ้งถ้ามี SSH แล้วAccept only the IPs of systems that really need it, and drop Telnet when SSH exists
  • เลิกใช้รหัส default ที่เหมือนกันทุกเครื่องStop using a default password that is the same on every unitรหัสในตารางด้านบนคือ list ที่บอทเดาทุกตัว ควรเป็นรหัสเฉพาะเครื่องThe passwords in the table above are the list every bot guesses; use a per-device password
  • TR-069 (7547) รับเฉพาะ ACSTR-069 (7547) from the ACS onlyตั้งที่ฝั่ง ONU ให้ connection request รับจาก IP ของ ACS เท่านั้นSet on the ONU side so connection requests are accepted only from the ACS IP

วิธีเก็บข้อมูล: Cowrie จำลอง shell ของ SSH/Telnet และตัวดักพอร์ต HTTP/TR-069 บันทึก request ดิบ ไม่มีคำสั่งไหนรันจริงบนเครื่อง ตัวเลขนับเฉพาะ IP ภายนอก (ตัด IP ของทีม 2 ตัวออก)How it is collected: Cowrie emulates the SSH/Telnet shell and a catcher on the HTTP/TR-069 ports records raw requests; no command really runs on the machine.
